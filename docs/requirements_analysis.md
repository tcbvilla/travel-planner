# 游戏考勤统计系统 - 需求分析与范围

## 背景与目标
- 面向《三国志战略版》同盟管理的考勤与奖惩统计。
- 基于两次导出的 CSV 比较“战功总量”，计算区间增量，判定出勤与统计分组表现。
- 可记录/导出考勤结果、缺勤名单，并维护赛季范围内的奖惩累计与榜单展示。

## 关键用户与场景
- 管理员：导入两份 CSV、设定出勤标准/奖惩规则、选择参评团队与人员、生成并导出结果图。
- 普通成员：查看个人与团队榜单、不可编辑的历史明细。

## 范围（MVP）
1) CSV 导入与校验；2) 战功增量计算与出勤判定；3) 分组统计（总增量/人均/出勤率）；4) 奖惩记录与三消逻辑；5) 结果导出为图片；6) 基础榜单/明细视图。

## 非目标（第一阶段不做）
- 游戏内自动抓取数据、复杂权限体系、移动端独立 APP（先做响应式 H5/PC）。

## 主要约束
- CSV 格式依赖游戏导出字段；
- 分组以考勤起始CSV为准（避免中途调整影响当次统计）。
