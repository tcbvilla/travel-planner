# CSV 数据规范与导入规则

## 来源与编码
- 来源：游戏“导出当前数据”功能。
- 建议编码：UTF-8（若为 GBK 需转码）。

## 必需字段（示例字段名，实际以样例 CSV 校对）
- 成员ID/UID（唯一标识）
- 成员昵称
- 分组/团队
- 战功总量（数值）

## 文件要求
- 两份 CSV：起始快照、结束快照。
- 成员匹配：以 成员ID 为主键对齐；若缺失则以 昵称+分组 兜底并标记“需人工确认”。

## 导入校验
- 字段存在性/类型；
- 重复成员行检测；
- 缺失成员在两次快照差异清单；
- 编码与分隔符自动探测；

## 计算口径
- 战功增量 = 结束快照.战功总量 - 起始快照.战功总量；
- 出勤判定：增量 >= 出勤标准（可配置，默认≥1或按盟规则设定）。
- 分组归属：以起始快照的“分组”为准。
