# 考勤管理系统权限设计文档

## 1. 系统概述

### 1.1 设计目标
- 基于角色的访问控制（RBAC）
- 数据共享，权限隔离
- 页面级和功能级权限控制
- 简单易用的登录认证系统
- 管理员统一管理用户账号

### 1.2 核心原则
- **数据共享**：所有用户访问同一份数据
- **权限分离**：不同角色具有不同的访问和操作权限
- **最小权限**：用户只获得完成工作所需的最小权限
- **易于管理**：管理员可以方便地管理用户和权限
- **灵活自定义**：支持完全自定义角色，无预设角色限制

## 2. 数据库设计

### 2.1 用户表（users）
```sql
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    display_name VARCHAR(100) NOT NULL,
    email VARCHAR(100),
    phone VARCHAR(20),
    status VARCHAR(20) DEFAULT 'ACTIVE', -- ACTIVE, DISABLED
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    created_by BIGINT REFERENCES users(id),
    last_login_at TIMESTAMP
);
```

### 2.2 角色表（roles）
```sql
CREATE TABLE roles (
    id BIGSERIAL PRIMARY KEY,
    code VARCHAR(50) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    created_by BIGINT REFERENCES users(id)
);
```

### 2.3 权限表（permissions）
```sql
CREATE TABLE permissions (
    id BIGSERIAL PRIMARY KEY,
    code VARCHAR(100) UNIQUE NOT NULL,
    name VARCHAR(100) NOT NULL,
    module VARCHAR(50) NOT NULL, -- 模块名称
    resource VARCHAR(50) NOT NULL, -- 资源名称
    action VARCHAR(50) NOT NULL, -- 操作类型
    description TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);
```

### 2.4 用户角色关联表（user_roles）
```sql
CREATE TABLE user_roles (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    role_id BIGINT NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    created_at TIMESTAMP DEFAULT NOW(),
    created_by BIGINT REFERENCES users(id),
    UNIQUE(user_id, role_id)
);
```

### 2.5 角色权限关联表（role_permissions）
```sql
CREATE TABLE role_permissions (
    id BIGSERIAL PRIMARY KEY,
    role_id BIGINT NOT NULL REFERENCES roles(id) ON DELETE CASCADE,
    permission_id BIGINT NOT NULL REFERENCES permissions(id) ON DELETE CASCADE,
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(role_id, permission_id)
);
```

## 3. 权限模型设计

### 3.1 权限编码规范
```
格式：{MODULE}:{RESOURCE}:{ACTION}
示例：
- ATTENDANCE:SESSION:VIEW     # 考勤记录查看
- ATTENDANCE:SESSION:CREATE   # 考勤记录创建
- ATTENDANCE:SESSION:EDIT     # 考勤记录编辑
- ATTENDANCE:SESSION:DELETE   # 考勤记录删除
- ATTENDANCE:SETTLEMENT:VIEW  # 结算查看
- RANKING:PAGE:VIEW           # 排行页面查看
- STATISTICS:EXPORT:USE       # 统计导出功能
```

### 3.2 模块划分
- **ATTENDANCE** - 考勤管理
- **RANKING** - 排行榜
- **STATISTICS** - 数据统计
- **SEASON** - 赛季管理
- **CONFIG** - 系统配置
- **USER** - 用户管理
- **SYSTEM** - 系统管理

### 3.3 资源类型
- **PAGE** - 页面访问
- **SESSION** - 考勤会话
- **SETTLEMENT** - 结算记录
- **EXPORT** - 导出功能
- **MANUAL_REWARD** - 手动奖惩
- **CONFIG_ITEM** - 配置项
- **USER_ACCOUNT** - 用户账号
- **ROLE** - 角色管理

### 3.4 操作类型
- **VIEW** - 查看
- **CREATE** - 创建
- **EDIT** - 编辑
- **DELETE** - 删除
- **USE** - 使用功能
- **EXPORT** - 导出
- **MANAGE** - 管理

## 4. 角色设计

### 4.1 角色特点
- **完全自定义**：所有角色都由管理员创建，无系统预设角色
- **灵活权限**：每个角色可以自由组合任意权限
- **动态管理**：角色可以随时创建、修改、删除
- **权限继承**：支持用户拥有多个角色，权限取并集

### 4.2 超级管理员
- **初始设置**：系统初始化时创建唯一的超级管理员账号
- **特殊权限**：拥有所有权限，包括用户管理和角色管理
- **不可删除**：超级管理员账号不可被删除
- **权限来源**：通过代码硬编码，不依赖角色系统

### 4.3 角色管理流程
1. **创建角色**：管理员定义角色名称和描述
2. **分配权限**：从权限列表中选择该角色需要的权限
3. **分配用户**：将角色分配给相应的用户
4. **动态调整**：根据需要随时修改角色权限

```java
// JWT Token 认证
@Component
public class JwtAuthenticationProvider {
    private String secretKey = "your-secret-key";
    private long validityInMilliseconds = 3600000; // 1小时
    
    public String createToken(String username, List<String> roles) {
        // 生成JWT Token
        Claims claims = Jwts.claims().setSubject(username);
        claims.put("roles", roles);
        Date now = new Date();
        Date validity = new Date(now.getTime() + validityInMilliseconds);
        
        return Jwts.builder()
            .setClaims(claims)
            .setIssuedAt(now)
            .setExpiration(validity)
            .signWith(SignatureAlgorithm.HS256, secretKey)
            .compact();
    }
    
    public Authentication getAuthentication(String token) {
        // 验证Token并返回认证信息
        Claims claims = Jwts.parser().setSigningKey(secretKey).parseClaimsJws(token).getBody();
        String username = claims.getSubject();
        List<String> roles = (List<String>) claims.get("roles");
        
        return new UsernamePasswordAuthenticationToken(username, "", 
            roles.stream().map(SimpleGrantedAuthority::new).collect(Collectors.toList()));
    }
}
```

#### 权限拦截器
```java
@Component
public class PermissionInterceptor implements HandlerInterceptor {
    
    @Autowired
    private UserService userService;
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                           HttpServletResponse response, 
                           Object handler) {
        
        // 检查是否是超级管理员
        String username = getCurrentUsername();
        if (userService.isSuperAdmin(username)) {
            return true; // 超级管理员拥有所有权限
        }
        
        RequirePermission annotation = getPermissionAnnotation(handler);
        if (annotation != null) {
            return checkUserPermission(username, annotation);
        }
        return true;
    }
    
    private boolean checkUserPermission(String username, RequirePermission annotation) {
        List<String> userPermissions = userService.getUserPermissions(username);
        
        // 检查单个权限
        if (!annotation.value().isEmpty()) {
            return userPermissions.contains(annotation.value());
        }
        
        // 检查任意权限
        if (annotation.anyOf().length > 0) {
            return Arrays.stream(annotation.anyOf())
                .anyMatch(userPermissions::contains);
        }
        
        // 检查所有权限
        if (annotation.allOf().length > 0) {
            return Arrays.stream(annotation.allOf())
                .allMatch(userPermissions::contains);
        }
        
        return false;
    }
}
```

#### 用户服务
```java
@Service
public class UserService {
    
    @Autowired
    private UserRepository userRepository;
    
    @Autowired
    private RoleRepository roleRepository;
    
    @Autowired
    private PermissionRepository permissionRepository;
    
    // 超级管理员用户名（可配置）
    private static final String SUPER_ADMIN_USERNAME = "admin";
    
    public UserDetails loadUserByUsername(String username) {
        User user = userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("用户不存在"));
        
        List<String> permissions = getUserPermissions(username);
        
        return org.springframework.security.core.userdetails.User.builder()
            .username(user.getUsername())
            .password(user.getPasswordHash())
            .authorities(permissions.stream()
                .map(SimpleGrantedAuthority::new)
                .collect(Collectors.toList()))
            .build();
    }
    
    public boolean isSuperAdmin(String username) {
        return SUPER_ADMIN_USERNAME.equals(username);
    }
    
    public boolean hasPermission(String username, String permission) {
        if (isSuperAdmin(username)) {
            return true;
        }
        return getUserPermissions(username).contains(permission);
    }
    
    public List<String> getUserPermissions(String username) {
        if (isSuperAdmin(username)) {
            // 超级管理员拥有所有权限
            return permissionRepository.findAll()
                .stream()
                .map(Permission::getCode)
                .collect(Collectors.toList());
        }
        
        // 获取用户的所有角色
        List<Role> userRoles = roleRepository.findByUsername(username);
        
        // 获取所有角色的权限（去重）
        return userRoles.stream()
            .flatMap(role -> role.getPermissions().stream())
            .map(Permission::getCode)
            .distinct()
            .collect(Collectors.toList());
    }
    
    public User createUser(String username, String password, String displayName) {
        User user = new User();
        user.setUsername(username);
        user.setPasswordHash(passwordEncoder.encode(password));
        user.setDisplayName(displayName);
        user.setStatus("ACTIVE");
        return userRepository.save(user);
    }
    
    public void resetPassword(Long userId, String newPassword) {
        User user = userRepository.findById(userId)
            .orElseThrow(() -> new RuntimeException("用户不存在"));
        user.setPasswordHash(passwordEncoder.encode(newPassword));
        userRepository.save(user);
    }
}
```

```typescript
// 路由权限守卫
const ProtectedRoute = ({ 
  children, 
  requiredPermission,
  anyOf = [],
  allOf = []
}: { 
  children: React.ReactNode, 
  requiredPermission?: string,
  anyOf?: string[],
  allOf?: string[]
}) => {
  const { hasPermission, hasAnyPermission, hasAllPermissions } = useAuth()
  
  let hasAccess = true;
  
  if (requiredPermission) {
    hasAccess = hasPermission(requiredPermission);
  } else if (anyOf.length > 0) {
    hasAccess = hasAnyPermission(anyOf);
  } else if (allOf.length > 0) {
    hasAccess = hasAllPermissions(allOf);
  }
  
  if (!hasAccess) {
    return (
      <div style={{ 
        textAlign: 'center', 
        padding: '50px', 
        color: '#999' 
      }}>
        <h3>无访问权限</h3>
        <p>您没有访问此页面的权限，请联系管理员</p>
      </div>
    );
  }
  
  return <>{children}</>;
}
```

#### 权限Hook
```typescript
// 权限管理Hook
export const useAuth = () => {
  const [user, setUser] = useState<User | null>(null);
  const [permissions, setPermissions] = useState<string[]>([]);
  const [isLoading, setIsLoading] = useState(true);
  
  useEffect(() => {
    loadUserInfo();
  }, []);
  
  const loadUserInfo = async () => {
    try {
      const token = localStorage.getItem('token');
      if (!token) {
        setIsLoading(false);
        return;
      }
      
      const response = await fetch('/api/auth/me', {
        headers: { Authorization: `Bearer ${token}` }
      });
      
      if (response.ok) {
        const userData = await response.json();
        setUser(userData.user);
        setPermissions(userData.permissions);
      } else {
        localStorage.removeItem('token');
      }
    } catch (error) {
      console.error('加载用户信息失败:', error);
    } finally {
      setIsLoading(false);
    }
  };
  
  const login = async (username: string, password: string) => {
    const response = await fetch('/api/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ username, password })
    });
    
    if (response.ok) {
      const data = await response.json();
      localStorage.setItem('token', data.token);
      setUser(data.user);
      setPermissions(data.permissions);
      return true;
    } else {
      throw new Error('登录失败');
    }
  };
  
  const logout = () => {
    localStorage.removeItem('token');
    setUser(null);
    setPermissions([]);
  };
  
  const hasPermission = (permission: string) => {
    return permissions.includes(permission);
  };
  
  const hasAnyPermission = (permissionList: string[]) => {
    return permissionList.some(p => permissions.includes(p));
  };
  
  const hasAllPermissions = (permissionList: string[]) => {
    return permissionList.every(p => permissions.includes(p));
  };
  
  const isSuperAdmin = () => {
    return user?.username === 'admin';
  };
  
  return { 
    user, 
    permissions, 
    isLoading,
    login,
    logout,
    hasPermission, 
    hasAnyPermission,
    hasAllPermissions,
    isSuperAdmin
  };
};
```

```typescript
// 权限控制组件
const PermissionWrapper = ({ 
  permission,
  anyOf = [],
  allOf = [],
  children, 
  fallback = null 
}: {
  permission?: string,
  anyOf?: string[],
  allOf?: string[],
  children: React.ReactNode,
  fallback?: React.ReactNode
}) => {
  const { hasPermission, hasAnyPermission, hasAllPermissions } = useAuth();
  
  let hasAccess = true;
  
  if (permission) {
    hasAccess = hasPermission(permission);
  } else if (anyOf.length > 0) {
    hasAccess = hasAnyPermission(anyOf);
  } else if (allOf.length > 0) {
    hasAccess = hasAllPermissions(allOf);
  }
  
  return hasAccess ? <>{children}</> : <>{fallback}</>;
};
```

### 7.1 密码安全

```java
@Service
public class PasswordService {
    
    private final BCryptPasswordEncoder passwordEncoder = new BCryptPasswordEncoder();
    
    public String encodePassword(String rawPassword) {
        return passwordEncoder.encode(rawPassword);
    }
    
    public boolean matches(String rawPassword, String encodedPassword) {
        return passwordEncoder.matches(rawPassword, encodedPassword);
    }
    
    public String generateRandomPassword() {
        // 生成8位随机密码
        String chars = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";
        StringBuilder password = new StringBuilder();
        Random random = new Random();
        for (int i = 0; i < 8; i++) {
            password.append(chars.charAt(random.nextInt(chars.length())));
        }
        return password.toString();
    }
}
```

```java
// Token刷新接口
@PostMapping("/auth/refresh")
public ResponseEntity<AuthResponse> refreshToken(@RequestHeader("Authorization") String token) {
    try {
        String username = jwtProvider.getUsernameFromToken(token);
        if (jwtProvider.isTokenValid(token)) {
            String newToken = jwtProvider.createToken(username, getUserRoles(username));
            return ResponseEntity.ok(new AuthResponse(newToken, getUserInfo(username)));
        }
    } catch (Exception e) {
        return ResponseEntity.status(HttpStatus.UNAUTHORIZED).build();
    }
    return ResponseEntity.status(HttpStatus.UNAUTHORIZED).build();
}
```

```java
// 操作日志记录
@Component
public class AuditLogger {
    
    @Autowired
    private AuditLogRepository auditLogRepository;
    
    public void logAction(String username, String action, String resourceType, 
                         String resourceId, Object details, HttpServletRequest request) {
        AuditLog log = new AuditLog();
        log.setUsername(username);
        log.setAction(action);
        log.setResourceType(resourceType);
        log.setResourceId(resourceId);
        log.setDetails(JsonUtils.toJson(details));
        log.setIpAddress(getClientIpAddress(request));
        log.setUserAgent(request.getHeader("User-Agent"));
        
        auditLogRepository.save(log);
    }
    
    private String getClientIpAddress(HttpServletRequest request) {
        String xForwardedFor = request.getHeader("X-Forwarded-For");
        if (xForwardedFor != null && !xForwardedFor.isEmpty()) {
            return xForwardedFor.split(",")[0].trim();
        }
        return request.getRemoteAddr();
    }
}
```

## 11. 总结

✅ **完全自定义**：无预设角色，所有角色由管理员创建和配置  
✅ **简化安全**：去除复杂的密码策略和登录限制，保持基础安全  
✅ **灵活权限**：支持页面级和功能级细粒度权限控制  
✅ **易于管理**：直观的用户和角色管理界面  
✅ **开发友好**：注解式权限控制，前后端统一权限模型  
✅ **安全可靠**：JWT认证 + BCrypt加密 + 操作审计  
✅ **扩展性强**：权限模型支持灵活扩展，适应业务发展  

该设计完全满足你的需求：
- 数据共享，权限隔离
- 页面级和功能级权限控制
- 完全自定义的角色系统
- 简单的用户管理和认证
- 超级管理员统一管理
- 适中的安全等级

系统实施后，管理员可以根据实际需要创建各种角色（如操作员、查看员、数据分析员等），并为每个角色分配合适的权限，实现精细化的访问控制。
