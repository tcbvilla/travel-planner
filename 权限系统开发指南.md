# 权限系统开发指南

## 📋 项目概述

基于考勤管理系统的RBAC权限系统开发，实现数据共享、权限隔离的访问控制机制。

### 开发目标
- 实现基于角色的访问控制（RBAC）
- 支持页面级和功能级权限控制
- 完全自定义角色系统
- 简单易用的用户管理
- 与现有考勤系统无缝集成

### 技术栈
- **后端**: Spring Boot + Spring Security + JWT + PostgreSQL
- **前端**: React + TypeScript + 权限Hook
- **数据库**: PostgreSQL + Liquibase

---

  ```typescript
  export const useAuth = () => {
    // 现有功能...
    
    const hasPermission = (permission: string) => {
      return permissions.includes(permission);
    };
    
    const hasAnyPermission = (permissionList: string[]) => {
      return permissionList.some(p => permissions.includes(p));
    };
    
    const hasAllPermissions = (permissionList: string[]) => {
      return permissionList.every(p => permissions.includes(p));
    };
    
    return { 
      // 现有返回值...
      hasPermission, 
      hasAnyPermission,
      hasAllPermissions
    };
  };
  ```

  ```typescript
  // 修改：hooks/useAuth.ts
  export const useAuth = () => {
    const [permissionCache, setPermissionCache] = useState<Map<string, boolean>>(new Map());
    
    const hasPermission = useCallback((permission: string) => {
      if (permissionCache.has(permission)) {
        return permissionCache.get(permission);
      }
      
      const result = permissions.includes(permission);
      setPermissionCache(prev => new Map(prev).set(permission, result));
      return result;
    }, [permissions, permissionCache]);
    
    // 清除缓存
    const clearPermissionCache = useCallback(() => {
      setPermissionCache(new Map());
    }, []);
    
    return { hasPermission, clearPermissionCache };
  };
  ```
